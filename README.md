# React User CRUD

A simple User Management CRUD application built with React, Axios, React Router, and JSON Server.

## 🚀 Features

- Add new users
- Display all users
- Edit existing users
- Delete users
- Email duplicate validation
- Form validation
- Confirm password validation
- Gender selection
- Country selection
- Toast notifications
- Dynamic routing for editing users

## 🛠️ Technologies Used

- React
- React Router DOM
- Axios
- JSON Server
- React Hot Toast
- Vite
- JavaScript
- CSS
